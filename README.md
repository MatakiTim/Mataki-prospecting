# Mataki Prospecting

Mataki's prospecting and inspection management platform.

## Architecture

- **Frontend:** GitHub Pages
- **Database and authentication:** Supabase
- **Documents and optional backups:** Box (planned)

## Product principles

- Keep the map interface modular and independently editable.
- Store business records in the cloud database, not in this public repository.
- Use authenticated access and database row-level security for customer information.
- Keep credentials and API secrets out of committed frontend code.

## Planned modules

1. Prospecting map and building records
2. Businesses and contacts
3. Visits and follow-ups
4. Quotes and sales pipeline
5. Inspection records and certificates
6. Document management

## Current status

Repository initialised. Cloud database and application deployment are not yet configured.
